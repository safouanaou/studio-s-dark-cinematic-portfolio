# FOS and KINU collateral library

This folder contains editable SVG source files for the digital collateral shown in the Studio S. portfolio. Print-ready PDF menus and business cards live in `output/pdf/`.

## Deliverables

### FOS

- Landscape digital menu board (1920 x 1080)
- Social story / portrait campaign display (1080 x 1920)
- Two-sided business card SVGs
- A4 print menu PDF
- Two-page business card PDF with 3 mm bleed

### KINU

- Landscape digital menu board (1920 x 1080)
- Seasonal social story / portrait display (1080 x 1920)
- Two-sided business card SVGs
- A4 seasonal print menu PDF
- Two-page business card PDF with 3 mm bleed

## Regenerate

Run `python3 collateral/generate_collateral.py` from the repository root. The generator keeps the source assets, PDF exports and portfolio previews consistent.

All names and contact details are fictional and created for portfolio demonstration purposes.
